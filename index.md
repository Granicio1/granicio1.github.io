# 🦴 codebone - See Your Code Like Never Before

## 🚀 What Is codebone?

codebone is a **macOS application** that creates a **live, visual map of your codebase** — like a GPS for your software project. It helps you understand how different parts of your code connect to each other, making it much easier to work on large projects, find bugs, or onboard new team members.

Think of it as a **smart blueprint** that updates itself as you write code. It doesn't just show you files and folders; it shows you the **relationships** between them — what depends on what, which parts talk to each other, and where the important pieces live.

The best part? It runs **entirely on your Mac** using a local AI model. Your code never leaves your computer, so your privacy is fully protected.

## 💻 System Requirements

To run codebone smoothly, your Mac should have:

- **macOS 13 (Ventura)** or newer
- **Apple Silicon (M1/M2/M3)** or Intel Mac
- **8GB RAM** minimum (16GB recommended)
- **5GB free disk space**
- An internet connection for the initial download (after that, it works offline)

## 🚀 Getting Started (Step-by-Step)

Follow these simple steps to get codebone up and running:

This link will take you to the official download page where you'll find the latest version of codebone for macOS.

### Step 2: Open the Downloaded File

Once the download finishes, look in your **Downloads** folder. You'll see a file called `codebone.dmg` (or similar). Double-click it to open it.

### Step 3: Drag to Applications

A window will appear showing the codebone icon. Simply **drag the codebone icon** into the **Applications** folder (which you'll see in the same window). That's it — codebone is now installed!

### Step 4: Launch codebone

Open your **Applications** folder and double-click the codebone icon. If you see a security warning, right-click the icon and select **"Open"** — this is normal for apps downloaded from the internet.

### Step 5: Connect Your Project

When codebone opens for the first time, you'll see a welcome screen. Click **"Choose Folder"** and select the main folder of your coding project. codebone will then begin building your knowledge graph automatically.

### Step 6: Explore Your Code Map

Once the graph is built, you can:
- **Click** any node to see details about that file or function
- **Drag** to pan around the map
- **Scroll** to zoom in and out
- **Use the search bar** to find specific components

## 🔌 Connecting to AI Coding Tools

codebone works with your favorite AI assistants through a standard called **MCP** (Model Context Protocol). Here's how to set it up:

### For Cursor, VS Code, or Claude Code:

1. Open your AI tool's settings
2. Look for **"MCP Servers"** or **"AI Integration"** section
3. Click **"Add MCP Server"**
4. Choose **codebone** from the list
5. Follow the on-screen instructions to complete the connection

Once connected, your AI assistant will have **real-time access** to your codebase structure, making its suggestions much more accurate and relevant.

## ❓ Frequently Asked Questions

### Is my code safe?

**Absolutely.** codebone runs entirely on your Mac. Your code, your project data, and all AI processing stay local. Nothing is sent to the cloud.

### Do I need to be a programmer to use this?

No! codebone is designed for everyone — from beginners to experts. The visual map makes it easy to see what's going on, even if you've never written a line of code.

### What is a "knowledge graph"?

Think of it as a **family tree** for your code. It shows which parts are connected to which, what depends on what, and how everything fits together. It's a visual representation of relationships.

### Can I use codebone with any programming language?

Yes, codebone supports most popular languages including Python, JavaScript, TypeScript, Java, C++, Go, Rust, and many more. It automatically detects the languages in your project.

### Does codebone slow down my computer?

No. codebone is optimized for performance and runs efficiently in the background. Most users notice no impact on their system speed.

### What if I have a really large project?

codebone handles projects of all sizes. For extremely large projects, it will take a bit longer to build the initial graph, but once complete, it updates in real-time as you code.

## 🛠️ Troubleshooting

### App won't open
If you see a warning that codebone cannot be opened, go to **System Settings → Privacy & Security** and click **"Open Anyway"** next to the codebone message.

### Graph is blank
Make sure you've selected the correct project folder. If the folder is empty or the code is in a different location, the graph won't appear.

### Slow performance
Close other heavy applications or try reducing the "Graph Refresh Rate" in settings.

### Can't connect to AI tools
Ensure both codebone and your AI tool are updated to the latest versions. Restart both applications and try again.
